# Answer questions from a channel

Choose a narrow question set for your first agent: support hours, a product FAQ, or internal process questions. Put the approved source material in its workspace, connect a channel, and send a real test question. Check both the reply and the [Activity](../dashboard/activity.md) record.

::: info In the browser
Use **Settings** to confirm the agent and channel assignment. Give the agent an instruction to say when it cannot find a reliable answer, rather than inventing one. Test a question with a known answer and one outside the source material.
:::

For a first channel, see [Connect Telegram](../connect-telegram.md). If no reply arrives, follow [It's not answering](../help/its-not-answering.md).
