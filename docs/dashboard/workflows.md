# Workflows — saved automations

Workflows is where you view and edit saved automations. Open a workflow to see its steps and how work moves between them. You can also use the editor's chat control to [describe an automation in plain English](../automations/describe-it.md).

Read a generated workflow before applying it. **Apply to canvas replaces the current graph.** Save only after the steps and destinations match what you intend. After it runs, [check the result](../automations/check-it-worked.md).
