# Activity — what ran, where, and what it decided

Monitor answers “what needs me?” Activity answers “what ran, where, and what did it decide?” Use Activity to investigate a completed task or a message that seems to have gone to the wrong agent.

You can look at the same recorded work by **agent, client, project, channel, or node**. Narrow the view to the message or time you care about, then inspect its route and outcome. For a message that never appears, go to [It's not answering](../help/its-not-answering.md) and check whether the channel reached the daemon.
