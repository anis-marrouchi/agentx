# Live — who's working now

Live shows active agents and recent work as it happens. Use it when you have just sent a task and want to see whether an agent picked it up. If no agent appears, check that the [daemon is running](../help/its-not-answering.md) and that the channel is connected.

Live is a current view. For completed work and the route it took, use [Activity](./activity.md). For work that needs your attention, use [Monitor](./monitor.md).
