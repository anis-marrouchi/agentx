# The things that run without you

A schedule starts work at a chosen time. A workflow ties steps together, including steps that need to survive a restart. You can [describe a workflow in plain English](./describe-it.md) in the editor, inspect the result, and then run it.

Start with one small job that has a visible output, such as a daily summary sent to a channel. Once it works, [check its history](./check-it-worked.md) before adding more steps.
