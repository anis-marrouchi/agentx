# AgentX

**زملاء عمل بالذكاء الاصطناعي ينجزون العمل في الأدوات التي يستخدمها فريقك أصلًا.**

يردّ وكلاؤك على العملاء في Telegram، ويراجعون طلبات الدمج في GitLab، ويرسلون تقرير الاثنين في موعده، وترى ما أُنجز في مكان واحد. يكفي ذلك ثلاث خطوات:

1. **أعطِ وكيلًا مهمّة.** قُل بكلمات بسيطة ما تريد إنجازه، مثل «الردّ على أسئلة الدعم» أو «إرسال ملخّص المبيعات الأسبوعي».
2. **ضعه حيث يجري العمل.** اربط Telegram أو WhatsApp أو GitLab أو GitHub أو موعدًا مجدولًا أو webhook، وسيردّ الوكيل هناك.
3. **تحقّق من النتيجة.** تعرض لوحة التحكّم في المتصفّح ما أُنجز وما يحتاج إلى شخص، فلا توافق إلا على ما يهمّ.

كيف يعمل: يعمل AgentX على جهاز تتحكّم فيه أنت. وهو منصّة تشغيل (harness)، أي البرنامج الذي يحيط بنموذج الذكاء الاصطناعي: يمنحه قنوات العمل والأدوات والمواعيد المجدولة والذاكرة، ويسجّل ما قام به. يعمل مع Claude Code أو Codex أو OpenCode أو أيّ واجهة برمجية لنموذج لغوي.

> هذه الصفحة ترجمة مختصرة للملف [README بالإنجليزية](https://github.com/anis-marrouchi/agentx#readme). الدليل الكامل متاح بالإنجليزية في [موقع التوثيق](https://agentx-docs.pages.dev/).

## الوضع الحالي: قابل للاستخدام، تجريبي، وليس مستقرًّا بعد

يعمل AgentX ويمكن استخدامه اليوم، لكنه ما زال **مشروعًا تجريبيًا وليس إصدارًا مستقرًّا**. هناك الكثير مما يحتاج إلى تحسين، خاصةً **تجربة الإعدادات ومسارات التهيئة**. توقّع بعض النواقص والتغييرات المتكرّرة. راجع [سجلّ التغييرات](https://github.com/anis-marrouchi/agentx/blob/main/CHANGELOG.md) لمعرفة ما تغيّر.

**ما زال ينقصه: التحكّم في الوصول حسب الأدوار (RBAC)** على مستوى الشبكة (mesh) وعلى مستوى الوكلاء. هذا عمل مخطّط له، وليس ميزة متوفّرة.

## جرّبه دون حساب

تحتاج إلى Node.js بإصدار 22.19 أو أحدث (حتى 26). شغّل في الطرفية:

</div>

```sh
npx agentix-cli demo
```

<div dir="rtl">

لا تحتاج إلى نسخ المستودع ولا إلى حساب ولا إلى مفتاح API. يشغّل العرض ثلاث نسخ محلية من AgentX ويرسل مهمّة بينها. التوجيه والاتصالات الشبكية وسجلّ الأحداث حقيقية، أمّا ردود النموذج فمكتوبة مسبقًا، لذلك لا يُجري العرض أيّ استدعاء مدفوع لنموذج. تطبع الطرفية عناوين لوحة التحكّم. [ماذا تتوقّع](../see-it-first.md).

## التثبيت

يحتاج التثبيت إلى شخص تقني يستخدم الطرفية لإعداد النموذج وتشغيل الخدمات، ثمّ يتولّى معالج الويب بقية الإعداد الأولي. خصّص من 10 إلى 20 دقيقة لأوّل تثبيت. يعمل AgentX على **macOS وLinux** (لم يُختبر على Windows؛ جرّب WSL).

باستخدام Docker:

</div>

```sh
git clone https://github.com/anis-marrouchi/agentx.git
cd agentx
cp .env.example .env
docker compose up --build -d
```

<div dir="rtl">

ثمّ افتح **http://127.0.0.1:4202/setup** في المتصفّح.

دون Docker، ثبّت Node.js 22.19 أو أحدث (حتى 26) وpnpm 10، ثمّ ابنِ المشروع وافتح المعالج:

</div>

```sh
pnpm install
pnpm build
node dist/cli.js setup
node dist/cli.js daemon start --detach
node dist/cli.js daemon status
```

<div dir="rtl">

اسم حزمة npm هو `agentix-cli`، والأمر المثبَّت هو `agentx`. التفاصيل في [دليل التثبيت](../install.md).

### أضِف AgentX إلى Claude Code

بعد تثبيت AgentX وتشغيله، يُثبّت أمر واحد إضافة AgentX في Claude Code (الإصدار 2.1.275 أو أحدث). تضمّ الإضافة خادم أدوات AgentX، ويعمل افتراضيًا في وضع القراءة فقط، إلى جانب مهارتين:

</div>

```sh
claude plugin install agentx --marketplace anis-marrouchi/agentx
```

<div dir="rtl">

ابدأ جلسة جديدة في Claude Code واطلب منه أن يتحقّق من عقدة AgentX لديك. [الخطوات والإعدادات](../jobs/install-the-plugin.md).

## ماذا يفعل

- **يجيب حيث يعمل فريقك.** اربط قناة واجعل وكيلًا يتولّى رسائلها.
- **ينفّذ العمل المجدول.** اطلب من وكيل تقريرًا يوميًا أو أيّ مهمّة متكرّرة.
- **يُظهر ما حدث.** تعرض صفحة Live العمل الجاري، وتسجّل صفحة Activity ما اكتمل، وتعرض صفحة Monitor ما يحتاج إلى تدخّل شخص.
- **يتّسع لأكثر من جهاز.** ابدأ بجهاز واحد، ثمّ اربط جهازًا آخر عندما تحتاج مهمّة إلى أدواته أو ملفاته.

## القنوات والنماذج

لـ Telegram وWhatsApp خطوات ربط خاصة. ويمكن لـ GitLab وGitHub وwebhooks العامة إدخال الأحداث. **لا يدعم هذا الإصدار Slack وDiscord كقنوات مباشرة.** [مرجع القنوات](../reference/channels.md).

يحتاج الوكلاء الحقيقيون إلى نموذج مُهيّأ. مزوّد الـ API يحتاج إلى مفتاح، وClaude Code وCodex CLI وOpenCode تحتاج إلى تثبيت أداتها وتسجيل الدخول على الجهاز.

## ساعدنا في الاختبار والتحسين

أكثر مساهمة قيمةً الآن هي **تجربة AgentX والإبلاغ عمّا يحدث**. لا تحتاج إلى كتابة كود للمساعدة.

1. **اختبر وأبلِغ عن المشكلات.** جرّب التثبيت والإعدادات وإعداد النموذج والمحادثة، ثمّ صِف ما توقّعته وما حدث فعلًا.
2. **ساعد في فرز المشكلات.** أعِد إنتاج البلاغات وحدّد المكرّر منها.
3. **ساهم في الكود والتوثيق.** ناقش التغييرات الكبيرة في issue أوّلًا.

[أبلِغ عن مشكلة](https://github.com/anis-marrouchi/agentx/issues/new/choose) بالإنجليزية، وأزِل أيّ أسرار أو بيانات خاصة قبل المشاركة. الثغرات الأمنية تُبلَّغ عبر [سياسة الأمان](https://github.com/anis-marrouchi/agentx/blob/main/SECURITY.md) وليس في issue علني. راجع [دليل المساهمة](https://github.com/anis-marrouchi/agentx/blob/main/CONTRIBUTING.md).

## تحقّق من أنه يعمل

1. **الطرفية:** شغّل `npx agentix-cli demo`.
2. افتح أحد عناوين لوحة التحكّم التي تطبعها الطرفية.
3. تظهر لوحة التحكّم وفيها المهمّة التي أُرسلت بين النسخ الثلاث.

## إذا حدث خطأ

- **رسائل `npm warn deprecated` أثناء التنزيل.** لا ضرر منها، وانتظر انتهاء التنزيل.
- **خطأ في إصدار Node.js.** شغّل `node --version`. يحتاج AgentX إلى الإصدار 22.19 أو أحدث، حتى 26.
- **مشكلة أخرى.** راجع [صفحة استكشاف الأخطاء](../help/its-not-answering.md)، أو [اطرح سؤالًا](https://github.com/anis-marrouchi/agentx/discussions).
