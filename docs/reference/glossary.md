# Glossary

**Agent:** An AI worker with a workspace, instructions, and a model. **Channel:** A connection that carries messages from an outside tool. **Daemon:** The background AgentX process that receives work and runs agents. **Dashboard:** The separate browser server for setup and inspection. **Schedule:** A timed trigger for a task. **Workflow:** A saved automation with steps. **Run:** One execution of a task or workflow. **Node:** A machine running AgentX. **Mesh:** Connected nodes that can hand work to one another. **Review:** A record from an external CLI session used by Monitor. **Activity:** The recorded history of work and routing decisions.

For commands and accepted configuration, see the [CLI](./cli.md) and [configuration](./config.md) references.
