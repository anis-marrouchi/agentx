# AgentX desktop app

Electron app that opens the daemon's Hub (`/hub`) in a window, with a top-bar
icon, for macOS, Windows and Ubuntu. User guide: `docs/guides/desktop-app.md`.

```bash
npm ci
npm test        # compile + unit tests for the URL and microphone rules
npm start       # run from source (needs the daemon on 127.0.0.1:4202)
npm run dist    # installer for this system, in release/
```

- `src/main.ts`: window, navigation, microphone permission, menus.
- `src/hub.ts`: which URLs stay in the window and which may use the microphone (no Electron, tested).
- `src/tray.ts`: the top-bar icon, adapted from Orca (MIT, see `LICENSE.orca`).
- Icons in `build/` and `resources/` are generated by `scripts/gen-icons.ts`; don't edit them by hand.
- CI: `.github/workflows/desktop.yml` builds all three systems and keeps the installers as artifacts.
